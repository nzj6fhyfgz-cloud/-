ST 国試トレーナー（PWA版）

内容:
- 分野別問題演習
- 苦手登録
- 20問/50問模試
- 科目別正答率
- 学習履歴を端末内に保存
- オフライン対応

使い方:
1. このフォルダをHTTPS対応のWebサーバーに公開してください。
2. iPhone: Safariで開く → 共有 →「ホーム画面に追加」
3. Android/Chrome: メニュー →「アプリをインストール」

注意:
- index.htmlを単体で直接開くことはできますが、PWAのインストール/Service WorkerはHTTPSまたはlocalhost環境が必要です。
- App Store / Google Playへ公開する場合は、このPWAをCapacitor等でiOS/Androidアプリに包む方法が簡単です。
